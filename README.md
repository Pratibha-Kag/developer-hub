# Personal Portfolio

A modern and responsive developer portfolio built with React.js and Vite.

## 🚀 Tech Stack

- React.js
- JavaScript
- Tailwind CSS
- Vite
- EmailJS

## ✨ Features

- Responsive design
- Modern and clean UI
- Smooth animations
- Projects showcase
- Skills and experience section
- Contact form with EmailJS
- Social media integration
